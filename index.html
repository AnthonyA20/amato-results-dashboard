Methodology. Run and Bike peak-performance figures are read directly from Intervals.icu's Pace Curves and Power Curves pages using a custom "All Time" season (Jan 1, 2015 start). The date shown under each Peak Performance value is the day that specific best effort was set, found by opening the source activity behind each curve/table cell on Intervals — several distances/durations share one date because a single workout produced more than one personal best at once (e.g. the Nov 1, 2025 run set the Last-365 bests for 400m through 5k in one go; the Jun 17, 2017 ride set both the all-time 3k and 10k power bests). "My Time"/distance in Race Reports combine the original TrainingPeaks race log with the matching imported activity file, used only to fill gaps TrainingPeaks itself was missing. Official Result, Placing, and Age-Graded come from your New York Road Runners results export and are matched by date first, then by name and finish-time proximity for the same year. One date correction was made this way: TrainingPeaks listed "Abbott Dash to the Finish Line 5K" under 7/4/2023, but NYRR's official record — and a matching Intervals activity — puts it on 11/4/2023 (marathon week), so the date shown here has been corrected.

Known limitations. Intervals.icu has no duration-based heart-rate curve (only Pace and Power support that), so Bike peak HR is a simple maximum rather than a true curve — 173 bpm was hit on separate rides in both 2021 and 2022, so that card shows both years rather than one date. This is a snapshot as of the date above, not a live feed — Intervals' curve computations aren't exposed through a CORS-enabled API, so refreshing requires re-running this confirmation pass. NYRR Gridiron 4M, 2/12/2023, has no matching entry in the NYRR export because it was run unregistered (bandit), not an NYRR-scored entry — expected, not a data error. Every race date was checked against the full Intervals activity history; the NYRR R-U-N 5K on 8/6/2015 was the one true gap found, and it's now resolved. Its device file wasn't missing because of anything in the dedup or upload pipeline — a different day's workout (8/7/2015) had silently overwritten it under the same generated export filename in the original raw TrainingPeaks archive, so the true 8/6 file was never in that archive to begin with. You downloaded the correct file directly from TrainingPeaks, it was converted and uploaded, and it's now confirmed live in Intervals (Afternoon Run, 8/6/2015, 28:33, 3.15mi). No other gaps of this kind were found across the other 66 races.
